Meal Demand Decision Support System

Python · PyQt6 · Streamlit · SQLite · Statistical Forecasting · Data Visualization

Project information

  • Category: Software Systems · Data Analytics · Statistical Modeling
  • Project type: Independent Academic & Research Project
  • Project date: June–August 2026
  • Status: Functional Desktop Application & Public Web Demonstration
  • Interfaces: PyQt6 Desktop · Streamlit Web
  • Role: Project Author · System Analyst · Software Developer · Database Designer · Statistical Model Designer · Technical Writer

A decision-support system developed around a real organizational catering workflow. It combines weekly menu planning, historical demand management, seven forecasting methods, 95% confidence intervals, MAE/MAPE/RMSE evaluation, SQLite persistence, and visual reporting through both desktop and browser-accessible interfaces.

The public repository and web application use anonymized and partially synthetic demonstration data. Realistic meal menus and operational relationships are preserved, while company identifiers, dates, and demand quantities are protected.
