Serial vs Parallel Sorting Benchmark

Python · Multiprocessing · Threading · Algorithm Analysis · Performance Measurement · Data Visualization

Project information

  • Category: Research & Experiments · Parallel Computing ·Performance Benchmarking
  • Project type:Academic Software & Computational Performance Experiment
  • Project date:December, 2025
  • Status:Completed Functional Benchmarking Application
  • Role: Project Author · Software Developer ·Performance Analyst · Experiment Designer · Technical Writer

A graphical benchmarking system for comparing serial, multithreaded, and multiprocessing implementations of Bubble Sort, Merge Sort, and Quick Sort across datasets of different sizes. The application measures execution time, speedup, efficiency, and scalability, while presenting the results through tables, charts, and heatmaps.
