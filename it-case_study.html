Information Theory Toolkit

Transforming abstract information-theory concepts into a desktop and browser-accessible computational environment.

The Problem

Information theory introduces abstract concepts such as entropy, redundancy, coding efficiency, prefix codes, conditional entropy, mutual information, and communication channel uncertainty. Although these concepts can be expressed mathematically, their relationships are often difficult to understand when they are presented only as isolated formulas.

Coding algorithms such as Shannon–Fano and Huffman also involve structured procedures whose behavior depends on symbol probabilities, tree construction, codeword lengths, and the resulting average code length.

The challenge was therefore to create one environment that connects theoretical definitions, algorithm execution, numerical results, code validation, channel analysis, and visual interpretation.

Project Motivation

The toolkit was developed to make information-theory processes observable. Instead of presenting only the final entropy value or generated code, the application reveals the distribution, algorithmic structure, coding tree, channel relationships, and compression result behind each calculation.

Project Objective

The objective was to develop a modular information-theory toolkit that supports source analysis, coding methods, prefix-code validation, communication-channel analysis, compression measurement, and direct method comparison.

The project was originally implemented as a Tkinter desktop application. A Streamlit web interface was later added so the same reusable algorithms can be accessed directly through a browser without duplicating the computational logic.

The project combines probability analysis, recursive algorithms, binary trees, channel models, interface design, data visualization, automated validation, and technical explanation.

Core Design Principle

Every result should remain explainable. Both interfaces connect each numerical output to the probability distribution, coding structure, transition matrix, or comparison from which it was derived.

Information-Theory Foundations

The toolkit is built around measures used to describe discrete information sources, source codes, and communication channels.

Source Entropy

H(X) = −Σ p(x) log₂ p(x)

Measures the average uncertainty produced by a discrete source.

Maximum Entropy

Hmax = log₂ n

Represents maximum uncertainty for n equally probable symbols.

Redundancy

R = 1 − H(X) / Hmax

Measures how far the source is from its maximum possible entropy.

Output Entropy

H(Y) = −Σ p(y) log₂ p(y)

Measures uncertainty in the channel output distribution.

Conditional Entropy

H(Y|X) = Σ p(x)H(Y|X=x)

Measures output uncertainty that remains when the input is known.

Mutual Information

I(X;Y) = H(Y) − H(Y|X)

Measures how much information about the input is retained at the output.

Core Application Modules

The desktop and web interfaces expose the same seven reusable analytical modules.

Entropy Analysis

Calculates Shannon entropy, maximum entropy, source redundancy, and validates probability distributions.

Huffman Coding

Builds a binary Huffman tree, generates codewords, calculates encoded length and compression ratio, and visualizes frequencies and the tree.

Shannon–Fano Coding

Orders symbols by frequency, applies recursive probability partitioning, generates binary codes, and reports encoded size.

Prefix-Code Analysis

Validates binary codewords, checks the prefix-free property, calculates the Kraft sum, and evaluates Kraft’s inequality.

Channel Analysis

Processes P(X) and P(Y|X), derives P(Y), and calculates H(X), H(Y), H(Y|X), and I(X;Y).

Compression Analysis

Calculates original and compressed size, compression ratio, entropy, average code length, and coding efficiency.

Method Comparison

Compares Huffman and Shannon–Fano encoded lengths, compression ratios, generated codes, and identifies the better result for the selected text.

Shannon–Fano Coding

The Shannon–Fano module begins by sorting symbols according to descending probability. It then recursively divides the distribution into two groups whose total probabilities are as close as possible.

One branch receives the binary value 0 and the other receives 1. The process continues until every symbol has a unique codeword.

The application presents the resulting code, codeword length, average length, coding efficiency, and relation to source entropy.

Huffman Coding

The Huffman module uses a priority-based tree construction process. Symbols with the lowest probabilities are repeatedly combined into parent nodes until a complete binary tree is formed.

Traversing the left and right branches generates the final prefix code. More probable symbols generally receive shorter codewords, while less probable symbols receive longer ones.

The toolkit also visualizes the Huffman tree so that the relationship between probabilities, merged nodes, and final codewords can be inspected directly.

Method Main Principle Structure Strength Limitation
Shannon–Fano Recursive division of sorted symbols into approximately equal-probability groups. Top-down code construction. Clear recursive logic and useful for demonstrating the relation between probability and code length. Does not always produce the optimal minimum average code length.
Huffman Repeated combination of the least probable nodes. Bottom-up binary tree construction. Produces an optimal binary prefix code for the given symbol probabilities. Requires tree construction and does not preserve the original symbol order.

Prefix-Free Validation and Kraft Inequality

The code-analysis module performs two related but distinct checks. It first verifies whether any codeword is a prefix of another codeword. It then calculates the Kraft sum for the supplied binary codes.

The prefix-free check evaluates the actual codewords, while Kraft’s inequality evaluates whether their lengths satisfy the necessary condition for a binary prefix code.

The application validates binary input, reports the prefix-free result, displays the calculated Kraft sum, and classifies the Kraft condition as valid or invalid.

Kraft Inequality

Σ 2−lᵢ ≤ 1

For binary codeword lengths, a sum not greater than one satisfies the Kraft condition.

Communication-Channel Analysis

The channel module analyzes a discrete memoryless channel from an input distribution P(X) and a transition matrix P(Y|X).

After validating the probability distribution, matrix dimensions, and row sums, the toolkit derives the output distribution P(Y) and calculates input entropy H(X), output entropy H(Y), conditional entropy H(Y|X), and mutual information I(X;Y).

The Streamlit interface also presents the transition matrix, the derived output distribution, and a directed channel graph so the probabilistic relationships can be inspected alongside the numerical results.

Analytical Value

Mutual information is derived from the complete channel model rather than entered as an isolated value. This shows how uncertainty changes between the input and output distributions.

Compression Analysis and Method Comparison

The compression module evaluates Huffman coding for a selected text by calculating the original UTF-8 size, compressed bit length, compression ratio, source entropy, average code length, and coding efficiency.

A separate comparison module generates both Huffman and Shannon–Fano codes for the same input, compares their encoded lengths and ratios, and identifies which method performs better for that particular distribution.

Original Representation

Establishes the baseline size from the UTF-8 representation of the selected text.

Compression Metrics

Reports compressed size, ratio, entropy, average code length, and efficiency.

Direct Method Comparison

Compares Huffman and Shannon–Fano results using the same source text and distribution.

Application Architecture

The toolkit separates interface code from reusable information-theory algorithms. The Tkinter desktop application and Streamlit web application call the same modules for calculations, coding, validation, and comparison.

Interface Layer

Tkinter desktop tabs and Streamlit browser pages, forms, tables, and controls.

Probability Layer

Distribution validation, entropy, maximum entropy, and redundancy calculations.

Coding Layer

Huffman tree construction, Shannon–Fano recursion, encoding, and code generation.

Analysis Layer

Prefix checks, Kraft evaluation, channel analysis, compression metrics, and method comparison.

Visualization Layer

Frequency charts, Huffman trees, channel graphs, tables, and comparison charts.

Testing and Validation

The reusable algorithmic layer is covered by seven automated tests. They verify representative calculations, coding behavior, edge cases, validation rules, compression metrics, and direct method comparison.

Entropy Metrics

Verifies entropy, maximum entropy, and redundancy for a balanced binary source.

Single-Symbol Huffman Edge Case

Confirms that a one-symbol source receives a valid one-bit code instead of an empty codeword.

Shannon–Fano Generation

Checks that every symbol in the selected source receives a non-empty codeword.

Prefix and Kraft Analysis

Verifies a known prefix-free code and confirms a Kraft sum equal to one.

Channel Analysis

Checks that the derived output distribution sums to one and that mutual information is non-negative.

Compression Metrics

Validates compressed length, compression ratio, and efficiency bounds for sample text.

Method Comparison

Confirms valid Huffman and Shannon–Fano results and the reported comparison outcome.

Project Outcome

The result is a completed Python toolkit with two interfaces: a Tkinter desktop application and a Streamlit web application. Both provide access to the same reusable modules for source analysis, coding, prefix-code validation, channel analysis, compression metrics, and method comparison.

The project demonstrates how theoretical information measures can be translated into modular algorithms, interactive interfaces, visual structures, and comparable computational results.

The public repository includes the source code, dependency files, application entry points, documentation, and automated tests.

Why This Project Matters

The toolkit connects probability, recursive algorithms, binary trees, channel models, visualization, software design, and browser deployment in one coherent analytical environment.

Project Strengths

  • Provides both desktop and browser-accessible interfaces.
  • Uses one reusable algorithmic layer across both interfaces.
  • Implements Huffman and Shannon–Fano coding.
  • Performs both direct prefix-free checking and Kraft evaluation.
  • Connects source coding with discrete communication-channel analysis.
  • Compares theoretical entropy with practical code length and compression results.
  • Includes automated tests for the core algorithms.

Current Limitations

  • The current version focuses on discrete, memoryless source and channel models.
  • Huffman and Shannon–Fano implementations generate binary codes.
  • The toolkit analyzes entered text rather than complete production file formats.
  • Channel analysis depends on correctly defined probability distributions and transition matrices.
  • Compression results do not include file-format headers, metadata overhead, or binary file export.

Future Development

The current desktop and web toolkit provides a stable base for a broader information-theory laboratory.

  • Arithmetic coding, run-length encoding, and Lempel–Ziv modules.
  • D-ary Huffman coding.
  • Encoding and decoding of complete text files.
  • Binary output generation and compressed-file export.
  • Channel-capacity calculations.
  • Error-correcting code demonstrations.
  • Larger matrix support and richer channel visualization.
  • Interactive step-by-step algorithm animation.
  • Expanded automated tests and benchmark datasets.
